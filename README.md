# AI Resume Analyzer

An AI-powered Resume Analyzer that helps job seekers evaluate their resumes against a specific job description and identify areas for improvement.

## 🚀 Features

- Upload your resume in PDF format
- Enter a target job description
- Analyze resume-job compatibility
- Identify relevant skills and missing skills
- Get an overall resume analysis
- Receive suggestions for improving the resume
- Simple and user-friendly web interface

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- PyPDF
- REST API
